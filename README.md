# دار العربية — منصة تعلّم اللغة العربية 🌙

موقع عربي متكامل (RTL بالكامل) لتعلّم اللغة العربية، يجمع في مكان واحد:

| القسم | المحتوى |
|---|---|
| 🔤 **الحروف** | الحروف الـ ٢٨ (في **بداية** الموقع والتنقّل): الاسم، الشكل، عدد النقاط، مخرج الحرف، صفاته، حركاته، مواضعه في الكلمة، أشهر الأخطاء، ونطق صوتي + **مقطع يوتيوب لكل حرف**. إضافةً إلى ١٢ مجموعة أصوات (المدّ، الهمز، اللين، التوسّط، الاستعلاء، الجهر والهمس، الشدّة والرخاوة، المطبّقة، المستطيلة) و١٠ مجموعات حروف متشابهة. |
| 📐 **القواعد** | ٢٦ درسًا في النحو والصرف: أقسام الكلام، المبتدأ والخبر، النواسخ، الفاعل، المفعول به، المفعول المطلق، الحال، النعت، البدل، التوكيد، العطف، الإضافة، الظروف، العدد، الممنوع من الصرف، المبنيات، حروف الجرّ، الأساليب، المشتقات، همزة الوصل والقطع، المقصور والممدود، علامات الإعراب، المصدر. |
| 🗂️ **المفردات** | ٩٣ مفردة موزّعة على ١٩ تصنيفًا، لكل مفردة: المعنى، الجذر اللغوي، نموذج من الاستعمال، المترادفات، المتضادات، وزرّ للاستماع ونسخ. |
| ⚖️ **الضد والعكس** | ٥٠ زوج متضاد + ٤٠ زوج مترادف، مع نموذج يوضّح الاستعمال. |
| 🧩 **الإعراب** | **محرّك إعراب آلي** يحلّ أي جملة تكتبها: نوع الجملة، إعراب كل كلمة مع علامته، شجرة نحوية، القواعد المطبَّقة، ومقاطع يوتيوب. إضافةً إلى ١٢ مثالًا محفوظًا بشجراتها النحوية، وكل مثال تعلوه بطاقة فيديو يشرحه. |
| 🎬 **فيديوهات** | ٦٢ مقطع يوتيوب **متحقَّق منها ومُدمجة فعليًا** داخل الموقع، موزّعة على ٨ تصنيفات (منها «الحروف والأصوات»). |
| 🖼️ **معرض الصور** | ارفع صورك بالسحب والإفلات (أو الاختيار)، تُصغَّر تلقائيًا إلى ٩٠٠ بكسل وتُحفظ في المتصفح، مع وصف لكل صورة وربطها بقاعدة لتظهر في صفحتها، مع عرض بالحجم الكامل وتنزيل وحذف. |
| 🔊 **النطق** | زر سرعة النطق في الرأس (بطيء جدًا / بطيء / واضح / عادي / سريع) يُحفظ في المتصفح، وزر «نطق الحرف (بطيء)» ينطق اسم الحرف **مرّتين ببطء ووضوح** ثم مثالًا من الكلمات. |
| 🔍 **البحث** | محرّك بحث واحد يغطّي كل الأقسام مع تظليل الكلمة المطابقة وفلاتر حسب النوع. |

### كيف يعمل البحث الآن؟

عند كتابة أي كلمة (مثل: *إعراب*، *المفعول به*، *الفرح*، *كان وأخواتها*، *الباء*) يظهر:

1. **💡 لوحة الإجابة المباشرة** — تُستخرج من محتوى الموقع نفسه (أقرب فقرة contain الكلمة)، مع زرّي «افتح الموضوع كاملًا» و«نسخ الإجابة».
2. **🎬 مقاطع يوتيوب مرتبطة** — ٣ مقاطع حقيقية بصور مصغّرة ومدة حقيقية، تُفتح وتعمل داخل الموقع، + بطاقة رابعة تفتح بحث يوتيوب عن الكلمة نفسها.
3. **قائمة النتائج** — كل نتيجة تحتوي **سطر «الإجابة:»** (ملخّص المضمون) + شريحة فيديو مصغّرة قابلة للنقر.

الترتيب يقدّم **المحتوى** (قواعد/إعراب/مفردات/حروف) على الفيديوهات، لأن الفيديوهات مُكمّلة لا أساسية.

### ✅ نعم — بعد كل حلٍّ يأتي مقطع يوتيوب

| الحالة | ما يظهر لك |
|---|---|
| **أعربت جملة** (من صفحة الإعراب) | إعراب كل كلمة + شجرة نحوية + **بطاقة فيديو تشرحها** (مثال: «إنَّ العلمَ نورٌ» ← شجرة + إعراب + «إنّ وأخواتها») |
| **جملة غير مسجَّلة** | يقترح **القواعد** المناسبة (يكشف نوع الجملة من الفعل) + ٣ مقاطع إعراب + رابط بحث يوتيوب بالجملة نفسها |
| **كل مثال إعراب في الصفحة** | بطاقة فيديو مصغّرة ملاصقة للحلّ (١٢/١٢) |
| **بحث في أي موضوع** | لوحة إجابة + ٣ مقاطع + شريحة فيديو في كل نتيجة |
| **كل حرف عربي** | زر المقطع الخاص بنطق ذلك الحرف |
| **كل درس قواعد** | قسم «فيديوهات مرتبطة» في نهاية الدرس |

## التشغيل

الملفات ثابتة بالكامل (HTML/CSS/JS) ولا تحتاج أي تثبيت.

### الطريقة الأولى — فتح الملف مباشرة
انقر نقرًا مزدوجًا على `index.html`.

### الطريقة الثانية — خادم محلي (مُستحسَن)
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\serve.ps1"
```
ثم افتح: <http://localhost:8765/>

## البنية

```
arabic-language-site/
├── index.html          # هيكل الصفحة (رأس، تنقّل، مشغّل فيديو، لوحة بحث)
├── serve.ps1           # خادم محلي بسيط بـ PowerShell
├── css/
│   └── style.css       # الثيم (زيتوني/ذهبي/كريمي) + استجابة كاملة + دعم RTL
└── js/
    ├── data-grammar.js # دروس القواعد (٢٦ درسًا بمحتوى HTML غني)
    ├── data-vocab.js   # المفردات + المترادفات + المتضادات
    ├── data-irab.js    # أمثلة الإعراب (أشجار نحوية) + مكتبة الفيديو
    ├── data-letters.js # الحروف الـ ٢٨ + مجموعات الأصوات + الحروف المتشابهة
    ├── data-yt.js      # خريطة مقاطع يوتيوب (المعرّف + المدة + العنوان)
    ├── engine.js       # محرّك الإعراب الآلي (معجم + تصريف + قواعد)
    ├── images.js       # معرض الصور (تخزين + تصغير + إدارة)
    └── app.js          # التوجيه، العرض، البحث، المشغّل، شجرة الإعراب
```

## المميزات التقنية

- **توجيه بالـ Hash** (`#/grammar/aslam`) — يعمل على أي استضافة ثابتة بلا إعادة تهيئة خادم.
- **رسم الأشجار النحوية بـ SVG** — خوارزمية تخطيط من الصفر (مقاسة تلقائيًا، مع دعم أدوار مثل `فاعل:`).
- **تطبيع النص العربي** قبل البحث: إزالة التشكيل والتطويل، وتوحيد الألف والياء والتاء المربوطة.
- **نطق صوتي** لكل مثال عبر `SpeechSynthesis`، و**نسخ** بنقرة واحدة.
- **مشغّل يوتيوب مدمج** يقبل رابطًا مباشرًا أو معرّف فيديو، مع روابط بحث احتياطية.
- **طباعة الدرس** (زر مخصّص + ورقة طباعة في CSS).
- اختصارات: `Ctrl/⌘ + K` أو `/` للبحث، `Esc` للإغلاق، `↑ ↓` للتنقّل بين النتائج.

## التخصيص

- **إضافة درس**: أضف كائنًا جديدًا إلى `GRAMMAR` في `js/data-grammar.js`.
- **إضافة مفردة**: أضف كائنًا إلى `VOCAB` في `js/data-vocab.js`.
- **إضافة مثال إعراب**: أضف إلى `IRAB` في `js/data-irab.js` مع شجرة `tree`.
- **تغيير الألوان**: كل الألوان معرّفة كمتغيّرات CSS في أعلى `css/style.css`.

> **ملاحظة:** مقاطع يوتيوب مرتبطة بمعرّفات حقيقية (YouTube Video ID)، لذا تعمل المشغّلات طالما كانت المعرّفات متاحة. ويمكن أيضًا لصق أي رابط يوتيوب في شريط المشغّل لمشاهدة مقطع غير مُدرج.
